# Lessons Learned

- Track evidence, not assumptions: tie claims to metrics.csv and synthesis/openlane logs.
- Separate local heavy artifacts from versioned evidence to keep repo practical.
- Submission structure should be enforced continuously, not only near deadline.
- Reduced secure modes can unblock closure, but must be documented clearly as configuration-specific outcomes.
- AI logs are most useful when preserved raw and summarized in focused derivatives.
- Keep a lightweight latest-run snapshot tracked in git while archiving full OpenLANE runs locally.
