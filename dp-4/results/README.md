# DP-4 Results (Team Farmceries)

This folder keeps compact, reproducible run snapshots for the Farmceries DP-4 tapeout flow.

Each run directory includes:
- `RUN_ID.txt`: authoritative run identifier
- `metrics.csv`: OpenLANE metrics for cross-phase PPA comparison
- `SUMMARY.md`: flow summary generated by automation
- `manufacturability.rpt`: manufacturability overview
- `openlane_flow.log.txt`: full flow log snapshot
- `command.txt`: exact invocation for reproducibility

Canonical final submission run:
- `RUN_2026.04.24_00.19.16`

Why we keep this folder compact:
- full implementation artifacts are promoted into `dp-4/gds`, `dp-4/netlist`, `dp-4/constraints`, and `dp-4/signoff`
- this avoids duplicate large files while preserving run provenance
